# SDK files with no counterpart in the original build at all.
#
# One path per line, relative to Source/SDK, case-insensitive. Listed here so
# Tools/sdk_coverage.py stops reporting them, keeping its output a real worklist.
#
# The test for inclusion is NOT "the linker map has no symbol for it". A fully
# inlined template emits no out-of-line code, so nothing reaches the map even
# though the type is unquestionably original -- BitArray<0x10000,unsigned int>
# and EARS::Common::SingleInternalLinkedListLightweight<RWS::CLinkedMsg> are
# both in that category, and an earlier version of this file wrongly called a
# dozen such files ours on exactly that reasoning.
#
# The test is: run Tools/pdb_find_type.py on every type the file declares. A
# file belongs here only when *none* of them appear in the PDBs. Checking the
# file's own stem proves nothing -- a stem is not a type name.
#
# If the types are original but no original file carries that name, the code
# lived somewhere else: that is Reference/consolidated.txt, not this file.
#
# Nothing currently qualifies. Every file previously listed here turned out to
# declare at least one original type.
